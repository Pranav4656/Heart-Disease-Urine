# Heart Disease Detection Using Urinary Biomarkers

A machine-learning research project exploring heart disease risk classification using urinary biomarkers and related clinical features.

## Overview

This project investigates two dataset-generation approaches—mechanistic and probabilistic—for studying the relationship between urinary biomarkers and heart disease risk. It includes data preprocessing, multiple machine-learning and deep-learning model implementations, evaluation outputs, and model-comparison visualizations.

**Research scope:** This is an experimental research prototype using generated datasets. Its outputs are not clinically validated and must not be used for medical diagnosis or treatment.

## Requirements

- Python 3.10 or a compatible version supported by the selected library releases
- pip
- A Windows, Linux, or macOS environment
- Internet access to install Python dependencies

TensorFlow and some scientific-computing packages may require compatible Python and platform versions.

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/Pranav4656/Heart-Disease-Urine.git
cd Heart-Disease-Urine
```

### 2. Create a virtual environment

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, use the environment's Python executable directly:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
```

### 3. Install dependencies

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Run experiments

Run scripts from the project root, for example:

```powershell
python preprocess.py
python train_random_forest.py
python train_random_forest_probabilistic.py
python train_xgboost.py
python train_xgboost_probabilistic.py
python train_lightgbm.py
python train_lightgbm_probabilistic.py
python train_cnn.py
python train_cnn_probabilistic.py
python train_crf.py
python train_crf_probabilistic.py
python train_swarm_mlp.py
python compare_all_models.py
python create_confusion_matrices.py
```

Run one experiment at a time. Check each script's configuration and input paths before execution. Some scripts may depend on preprocessing or outputs generated by earlier experiments. The commands above are entry points, not a guarantee that every experiment runs independently or in this exact sequence.

## Datasets

The `data/` directory contains the mechanistic and probabilistic datasets. Review their data-generation assumptions, feature definitions, and target-label construction before interpreting experimental results.

Generated datasets do not establish clinical validity. Any conclusions are limited to the assumptions and data used in these experiments.

## Reproducibility

- Use the same dependency versions and random seeds when reproducing experiments.
- Retain experiment configuration and evaluation metrics.
- Regenerate local models and intermediate files by running the appropriate scripts.
- Review output paths before running scripts that overwrite existing experiment results.

## Limitations

- The datasets are generated for research and are not a substitute for validated clinical data.
- Performance on generated data does not establish generalization to real patients.
- Clinical validation, external testing, and independent replication are required before any medical application.
